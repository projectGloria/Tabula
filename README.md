# Tabula

A local-first, offline, hand-drawn whiteboard that runs in the browser. Nothing is sent anywhere.

Status: early development. See `STATE.md` for progress and `INITIAL_PLAN.md` for the full plan.

## Develop

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm test
npm run lint
```
